51## 默认关闭的运行观测 V1
52
53`PAIREC_NATIVE_KEY_DIAGNOSTICS=1` 是**推理进程环境变量**，默认关闭；需同时编译新版 gateway 和打补丁的 native 库。仅在成功执行的每个 sample 后记录 `native_key_request_v1`：request_id、correlation_id、原来的 seed、输入/输出数量及 FNV-1a token 摘要。不固定 seed、不改采样、不输出原始 token。
54
55`native_key_block_v1` 在 buildBlockKeys 处记录 key、当前归因 request_id（无作用域时为 null）、零起始位置区间、原 prompt 长度和 prompt/generated/mixed 角色。这是**构造记录**，须和现有成功 offload 的 key 对齐才算实际写入。角色按原 prompt 边界划分，仅适用于已核实的完整序列、非滑动窗口路径；跨请求复用、切片或哈希歧义不能直接推断所属请求。`native_key_unlink_v1` 只表示本地树解除引用，绝不表示 DS Delete/TTL 已发生。无需新增无界内存映射。
56
57开启时新增日志和摘要计算可能影响 E2E，诊断组不能作为时延 A/B。仍限制 n3，不开放20/300/1000。需要保留准备和正式日志，检查：
58
591. 输入摘要是否相同、seed/输出摘要是否变化。
602. 首次见 offload key 是否能匹配 generated/mixed 构造记录；缺失/多种角色显式 UNKNOWN。
613. 本地 unlink 后对应 DS 对象是否仍保留（日志本身不提供 DS 逐 key 库存）。

74### 隔离构建，不覆盖正在运行的 runtime
75
76先确认磁盘空间足够保存 native 源码/构建树和新产物。在 worker1 执行，`REPO_DIR` 设为本次更新的仓库绝对路径：
77
78```bash
79: "${REPO_DIR:?设为 worker1 上本次更新的仓库路径}"
80KDIAG=/home/zcx/native-key-diag-$(date +%Y%m%d-%H%M%S)
81mkdir -p "$KDIAG"
82cp -a --reflink=auto /home/zcx/TensorRT-LLM "$KDIAG/TensorRT-LLM"
83TRTLLM_DIR="$KDIAG/TensorRT-LLM" RUNTIME_DIR="$KDIAG/runtime" \
84  APPLY_PATCH=0 APPLY_KVC_BURST_PROXY=0 APPLY_NATIVE_KEY_DIAGNOSTICS=1 \
85  BUILD_TRTLLM=1 bash "$REPO_DIR/scripts/build_f19_attribution_runtime_worker1.sh" \
86  > "$KDIAG/build.log" 2>&1
87cat "$KDIAG/runtime/native-key-build.sha256"
88```
89
90沿用已打 attribution/proxy 补丁的源码，避免重打旧补丁覆盖新观测。现有构建脚本在容器仍挂载到 `/TensorRT-LLM`；若历史 CMakeCache 使用其他绝对路径，应检查并重新配置，不能绕过构建失败。脚本末尾通用 overlay 部署提示不适用于此隔离诊断产物，**此处先不执行该提示**。

92后续部署必须把 gateway/native 库一起指向新目录，并在进程启动前设置诊断环境变量。当前还未执行远端编译、部署或重新测量；部署前需核对现有 volumeMount/overlay 行为及回滚路径。构建 hash 清单仅关联本次文件与产物，不替代进程 `/proc/PID/exe`、maps 映射 inode/加载库和容器身份验证。
